## 1. RÉPONDRE AUX COMMENTAIRES SUR NOS POSTS

Quand quelqu'un commente un post de R (Twitter, LinkedIn, Reddit, Facebook), R répond. Le but : convertir l'intérêt en beta tester ou client.

### Par type de commentaire

**"Comment ça marche ?" / "C'est quoi exactement ?"**
FRAMEWORK : Explication courte du résultat, pas du process technique. Ce que le produit TROUVE, pas comment il est codé. Finir par une proposition de DM pour montrer un scan.
ANGLE R : impact business. "it scans your store in 60 seconds and tells you exactly which apps are costing you money."

**"Intéressé" / "Comment tester ?" / "Where can I try this?"**
FRAMEWORK : Réponse immédiate. DM direct avec le lien. Pas de blabla. Chaque seconde de délai = perte de conversion.
"DMing you the link right now"

**"Combien ça coûte ?" / "What's the pricing?"**
FRAMEWORK : Donner les tiers rapidement. Free = 1 audit. Starter = $39/mois. Pro = $99/mois. Agency = $249/mois. Proposer de DM pour un scan gratuit avant de décider.
"free scan first, then $39/mo if you want it running continuously. sending you a DM"

**Question sur une feature spécifique**
FRAMEWORK : Répondre directement avec ce que le produit fait. Pas de "we're working on it" sauf si c'est vrai. Si la feature existe, dire ce qu'elle détecte concrètement. Si elle n'existe pas, dire "not yet but noted".

**Scepticisme / "Another tool that does nothing"**
FRAMEWORK : Pas défensif. Répondre avec un résultat concret. "ran a scan on a store last week, found 6 ghost apps billing $87/month. the merchant had no idea." Laisser le résultat parler.

**Critique technique / "This can't work because..."**
FRAMEWORK : R n'est pas le tech. Répondre sur l'angle business (le résultat, pas le comment). Si c'est vraiment technique, taguer ou rediriger vers F.

**"I have X problem with my store"**
FRAMEWORK : Diagnostic rapide basé sur ce que le merchant décrit. Si le problème est dans le scope de StoreMD, proposer un scan. Si hors scope, aider quand même (1-2 phrases) sans forcer le produit.

**Commentaire positif / "This is great"**
FRAMEWORK : Remercier en 1 phrase, pas plus. "appreciate it. lmk if you want a scan on your store" Pas de "Thanks so much! We're really glad you liked it!" — c'est IA.

## 2. POSTS REDDIT / FACEBOOK APRÈS J22

Quand R poste ou commente sur r/shopify, r/ecommerce, groupes Facebook Shopify. Le produit peut être mentionné naturellement dans le contexte d'une réponse utile. Ratio 90/10.

### Par type de thread

**"Mon store ne convertit pas" / "Low conversion rate"**
FRAMEWORK : Diagnostic en 1-2 points. Pas 3 points symétriques (anti-IA). Identifier le problème le plus probable. Donner 1 fix concret. Si pertinent (J22+), mentionner le scan comme "something I've been testing on stores with this exact issue".

**"Quel outil pour X ?" / "Best tool for..."**
FRAMEWORK : Comparaison honnête de 2-3 options. Si un de nos produits est pertinent, le mentionner en dernier, comme "I've also been using [produit] for this" — jamais en premier, jamais en mode pitch.

**"J'ai fait X et ça ne marche pas"**
FRAMEWORK : Retour d'expérience. "I've seen this on a bunch of stores." Puis ce qui a fonctionné. Résultat concret. Si le produit a détecté ce problème, le mentionner naturellement.

**"Comment avoir plus de trafic ?"**
FRAMEWORK : Recentrer sur le vrai problème. Si le merchant a un problème de vitesse ou d'app bloat, le diagnostic est plus utile que des conseils traffic. Donner 1-2 canaux concrets gratuits.

**"Store lent / Speed issues"**
FRAMEWORK : C'est le terrain de StoreMD. Expliquer que c'est souvent les apps, pas les images. Donner un quick fix vérifiable (ctrl+F '<script' dans le source). Si J22+, mentionner le scan.

**"Ghost billing / Chargebacks / Apps problems"**
FRAMEWORK : Data-drop. Commencer par un chiffre ("seen stores lose $50-200/month on apps they uninstalled months ago"). Expliquer le problème. Si J22+, mentionner le scan comme ce qui détecte ça automatiquement.

**Question technique (code, theme, API)**
FRAMEWORK : R ne répond pas en profondeur sur le technique. Donner une direction business si pertinent. Sinon laisser le thread à d'autres ou à F.
