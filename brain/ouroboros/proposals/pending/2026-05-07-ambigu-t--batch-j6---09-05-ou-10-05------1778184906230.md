**Titre:** Ambiguïté batch J6 : 09/05 ou 10/05 ? — L'erreur "Lundi 05/05" bloque la planification
**Contexte:** Le plan-30-jours F+R (lu aujourd'hui) indique "J1 = Lundi 05/05/2026 | J6 = premier batch-semaine (samedi)". Problème : 05/05/2026 est un **mardi**, pas un lundi. Si J1 = lundi 04/05 (intention réelle), alors J6 = **samedi 09/05** — c'est-à-dire **dans 2 jours**. Si J1 = 05/05 (date écrite), J6 = **dimanche 10/05** — qui n'est pas un samedi. L'erreur de date crée une incertitude sur la date réelle du premier batch. La pending correction ("Corriger plan-30-jours F — 05/05 est un mardi") ne donne pas de verdict sur J6.
**Recommandation:** Confirmer que J1 = **lundi 04/05** (donc J6 = **samedi 09/05**) et corriger le libellé dans les deux plans. Le batch devrait donc avoir lieu **dans 2 jours**. Si J1 = 04/05 est correct, les prérequis batch (archiver S7, créer progress.md S8, créer cold-logs) doivent être traités **avant samedi matin**.
**Risques si ignoré:** F et R peuvent manquer le batch d'un jour (09/05 vs 10/05) sur la base d'une lecture différente de la date J1. Une semaine de publication entière (Twitter F, Twitter R, LinkedIn, StoreMD) ne serait pas batchée à temps.
