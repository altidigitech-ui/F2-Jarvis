# Métriques — Guide de collecte

## Quand
Chaque **samedi**, AVANT de commencer la rédaction du batch.

## Quoi
1. **Métriques produit** → `storemd-admin.md` : ouvrir `/dashboard/admin`, copier les chiffres
2. **Métriques réseaux** → `[plateforme].md` : ouvrir les analytics natifs de chaque plateforme, copier les stats de la semaine

## Comment
- Copier les chiffres réels. JAMAIS inventer.
- Ajouter une nouvelle ligne dans le tableau de la semaine en cours.
- Ne pas supprimer les semaines précédentes (historique).
